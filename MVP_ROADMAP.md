# MVP Roadmap

## Increment 0: Project Setup
Goal: Create project foundation.

Deliverables:
- Next.js project setup
- Tailwind CSS setup
- Supabase project connection
- Environment variables
- Basic folder structure
- README setup instructions

Status: Not started

## Increment 1: Curator Posting MVP
Goal: Allow users to post dish recommendations.

Features:
- Sign up / sign in
- User profile
- Add restaurant
- Add dish recommendation
- Upload image
- Rating 1-5
- Tags
- Personally tasted checkbox
- Home feed

Success Criteria:
- A user can create and view dish recommendations.
- Data is persisted in Supabase.
- Image upload works.

Status: Not started

## Increment 2: Dish Discovery
Goal: Help users find dishes based on preferences.

Features:
- Search by dish name
- Filter by cuisine
- Filter by tags
- Filter by vegetarian/non-vegetarian
- Filter by spicy level
- Filter by budget
- Restaurant detail page
- Dish detail page

Success Criteria:
- A user can find relevant dishes quickly.

Status: Not started

## Increment 3: Curator Trust Layer
Goal: Make recommendations more credible.

Features:
- Curator profile page
- Curator dish count
- Likes/saves
- Report content
- Verified staff flag, admin-managed initially
- Curator specialties

Success Criteria:
- Users can understand why a curator is trustworthy.

Status: Not started

## Increment 4: Saved Dishes and Collections
Goal: Improve retention.

Features:
- Save dish
- Create personal food lists
- Share collection link
- Follow curator

Success Criteria:
- Users come back to saved recommendations.

Status: Not started

## Increment 5: AI Assistant
Goal: Add conversational food discovery after sufficient content exists.

Features:
- Natural language search
- Taste preference matching
- Recommendation explanation
- Dish suggestions based on tags and curator trust

Example:
User: I want spicy vegetarian food near me under $20.
Assistant: Recommends matching dishes with reasons and curator source.

Success Criteria:
- AI recommendations are useful and grounded in real dish data.

Status: Future
